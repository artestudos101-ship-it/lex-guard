# Acessibilidade

Controles devem ter nome acessível, foco visível, contraste sem depender apenas da cor e labels para inputs. Tabelas usam cabeçalhos semânticos; dialogs têm título; ações de PDF têm aria-label; atualizações do processamento usam `aria-live="polite"`. A redução de movimento é respeitada nos estilos globais.
